# Replay-харнесс prediction (оффлайн-контур)

Измерительный стенд модели v3.1: файлы на входе — файлы/метрики на выходе.
Никаких Redis / Spring / Reactor / прод-пайплайна (закреплено `OfflineContourPurityTest`).

## Как прогнать одной командой

```bash
# весь стенд (формат, метрики, модели, сценарии 15/16 с базлайнами):
./mvnw test -Dtest='biz.ugur.busroutebackend.replay.**'

# только сценарии (печатают базлайны и хэши):
./mvnw test -Dtest=ReplayScenariosTest
```

## Стоп-слой + ETA v1 (шаг A4)

- Фикстуры несут `stops[]` (id, seq, s из свежего снапа; 25/10/8 — 0 инверсий).
- События (§8): DECEL_ENTER / DWELL_ENTER / DWELL_EXIT / SKIP / AT_TERMINAL / DWELL_OUTLIER —
  интерфейс `StopAware` (`etas()`, `drainEvents()`); TURNING/NEW_TRIP — UNIMPLEMENTED (инкремент 3).
- DWELL пинит `x = x_stop`; вход `|x−x_stop|≤ε_stop ∧ raw<v_stop` ≥2 фикса; выход по
  `dwell_expected`(конфиг, 20 с) ∨ `raw≥v_move`; SKIP — по принятому снапу z_x (прогресс),
  событие только если min raw-скорость в зоне ≥ v_move.
- DECEL-профиль §4.3 капит прогнозную v ТОЛЬКО между фиксами (τ>2·dt) И при подтверждённом
  замедлении (последний raw < 0.95·V) — измерения правят прогноз.
- **ETA v1 (INV-11):** из того же x̂; кинематика (разгон a/крейсер/торможение) на целевой стоп от
  текущей v̂ и на сегменты стоп-стоп; стоянка стопа учитывается ПОСЛЕ его собственного ETA;
  в DWELL — остаток dwell; reliable=false в RECOVERING/GPS_LOST/NO_GPS.
- **Пороги A4 (стенд v1):** headline p95|ETA−факт| ≤ 15/25/60 с на горизонтах ≤60/≤120/≤300 с
  (факт: **13.2 / 14.5 / 13.1 с**, мультистоп с dwell-джиттером ±30% и σ=5);
  детектор П-2 vs истина ≤10 с; дрейф в DWELL ≤ ε_dwell=15 м; SC09 — «предельный цикл» =
  повторный DECEL_ENTER к одному стопу (=0), полное число смен mode — печатается.

## Терминалы/флип + история (шаг A5)

**Топология (Р-5/INV-15):** фикстура несёт `topology ∈ {there-and-back, loop}`
(дефолт there-and-back; `branching` — honest-заглушка, `RouteTopology.of` печатает и бросает).
Композит `RouteTopology.thereAndBack(dir0, dir1)` даёт ядру оба плеча; loop — одно кольцо.
Правила: wrap только loop (x←x−L, без смены d, без сброса P; счётчик оборотов `lapCount()`);
флип d и кламп `x=L_d → AT_TERMINAL` — только there-and-back.

**Терминальная цепочка:** вход AT_TERMINAL при `x ≥ L_d − ε_term`; стопы, чья зона пересекает
ε_term (включая `s' ≤ ε_term` обратного плеча), принадлежат терминальной ветке — стоп-слой их
не обслуживает (дубля ARRIVAL+TERMINAL нет). В AT_TERMINAL метка пинится на `x = L_d`.
Признак разворота — реальное продвижение (дух INV-9): TURNING только при
`N=3` подряд принятых снапах на L_{d'} с монотонным ростом и Σ ≥ `D_turn_confirm=40 м`
(близость без продвижения — не признак). TURNING держит последнюю точку; возврат — `K=3`
принятых снапа обратно на L_d. NEW_TRIP: `x = z_x'` ПЕРВОГО подтверждённого снапа
(минимизирует |Δp| цепочки), `P = P_init`, `trip_id++` ровно раз, → TRACKING по первой
штатной привязке. Факт |Δp|: route 10 — 0.0–3.7 м; route 8 — ~70 м (конечные плеч
физически разнесены на ~77 м — порог там калибровочный 150 м).

**Найдено в TDD A5 (алиасинг зоны):** жёсткое торможение в стоп пересекает DECEL-зону [0, ε_arr]
между 7-с фиксами (x̂ с крейсерской v̂ перепрыгивает зону, gate режет коррекции, прогресс
«проезжает» стоп). Лечение в духе A4: **вход в DECEL и учёт min-скорости зоны — также по
принятому снапу z_x**, не только по x̂ (измерения правят прогноз). Побочный эффект:
headline A4 улучшился до 7.8/14.5/12.5 с.

**История сегментов/dwell (батч-вход D, §0.5):** `HistoryAccumulator` (оффлайн-джоб) строит
из прогонов по П-2-выходам (не по истине): `hist_dwell[stop_id] → {mean, n}`,
`hist_seg[from|to|hour_bin|weekend] → {mean, n}`; выбросы `dwell > dwell_max` не входят.
Подключение (read-only `SegmentDwellHistory`, ядро писателя не видит — purity-тест):
`dwell_expected(stop)` = история при `n ≥ N_min=5`, иначе константа 20 с;
`t_seg` полных легов ETA = история при совпадении hour_bin, иначе кинематика;
`v_target` сегмента для §4.1/§6 — из истории при наличии. Первый лег (x̂ → ближайший стоп) —
всегда кинематика. Приёмка: dwell 10/20/45 с — история p95 17.6/18.0 с против константы
28.9/28.9 с (те же сиды); OOD-стоп → fallback в порогах; выброс 900 с в историю не попал.

**Honest-границы v1 (A5.5):** ETA через разворот не считается (только остановки впереди на
текущей линии); OFF_ROUTE — заглушка (FSM 11/12); branching вне scope.

**Baseline-артефакт:** `reports/eta-baseline-null-model.md` (нулевая модель Δs/v_target vs ядро,
генерируется `EtaBaselineReportTest`).

## NIS / NIS*

У референс-моделей (без предсказания) колонка — **NIS\*** (суррогат: шаг оценки между
фиксами). У ядра (`MotionFilterCore`, интерфейс `InnovationAware`) — **настоящий NIS**:
ν = z_x − x⁻, S = P₀₀ + R.

## SC15: почему «ошибка к истине» — НЕ критерий (обязательное пояснение)

На рампе SC15 измерения систематически смещены — истина недостижима ЛЮБОЙ каузальной
моделью (следящий снап честно уезжает вместе с измерениями: базлайн early≈24 м →
late≈86 м, линейный рост — портрет Н-1). Критерий Н-1 для ядра:
**ограниченность абсолютного отклонения** |Γ(x̂) − raw| против D_max (INV-3, независимо
от пер-тиковых дельт) + **детекция** устойчивого расхождения (N_persist → RECOVERING →
ре-привязка ≤ M подтверждений). Ассерт: ни одного тика, где absDev > D_max и событие
дрейфа не активно.
