# Replay-харнесс prediction (оффлайн-контур)

Измерительный стенд модели v3.1: файлы на входе — файлы/метрики на выходе.
Никаких Redis / Spring / Reactor / прод-пайплайна (закреплено `OfflineContourPurityTest`).

## Как прогнать одной командой

```bash
# весь стенд (формат, метрики, модели, сценарии 15/16 с базлайнами):
./mvnw test -Dtest='biz.ugur.busroutebackend.replay.**'

# только сценарии (печатают базлайны и хэши):
./mvnw test -Dtest=ReplayScenariosTest
```

## Экспорт геометрии из dev-БД (read-only, по требованию)

```bash
./mvnw test -Dtest=GeometryFixtureExporterTest \
  -Dgeometry.export=true -Dgeometry.pass=$DB_PASSWORD \
  -Dgeometry.routes=25,10,8
# → src/test/resources/fixtures/geometry/route-<N>-dir<D>.json
```

## Стоп-слой + ETA v1 (шаг A4)

- Фикстуры несут `stops[]` (id, seq, s из свежего снапа; 25/10/8 — 0 инверсий).
- События (§8): DECEL_ENTER / DWELL_ENTER / DWELL_EXIT / SKIP / AT_TERMINAL / DWELL_OUTLIER —
  интерфейс `StopAware` (`etas()`, `drainEvents()`); TURNING/NEW_TRIP — UNIMPLEMENTED (инкремент 3).
- DWELL пинит `x = x_stop`; вход `|x−x_stop|≤ε_stop ∧ raw<v_stop` ≥2 фикса; выход по
  `dwell_expected`(конфиг, 20 с) ∨ `raw≥v_move`; SKIP — по принятому снапу z_x (прогресс),
  событие только если min raw-скорость в зоне ≥ v_move.
- DECEL-профиль §4.3 капит прогнозную v ТОЛЬКО между фиксами (τ>2·dt) И при подтверждённом
  замедлении (последний raw < 0.95·V) — измерения правят прогноз.
- **ETA v1 (INV-11):** из того же x̂; кинематика (разгон a/крейсер/торможение) на целевой стоп от
  текущей v̂ и на сегменты стоп-стоп; стоянка стопа учитывается ПОСЛЕ его собственного ETA;
  в DWELL — остаток dwell; reliable=false в RECOVERING/GPS_LOST/NO_GPS.
- **Пороги A4 (стенд v1):** headline p95|ETA−факт| ≤ 15/25/60 с на горизонтах ≤60/≤120/≤300 с
  (факт: **13.2 / 14.5 / 13.1 с**, мультистоп с dwell-джиттером ±30% и σ=5);
  детектор П-2 vs истина ≤10 с; дрейф в DWELL ≤ ε_dwell=15 м; SC09 — «предельный цикл» =
  повторный DECEL_ENTER к одному стопу (=0), полное число смен mode — печатается.

## NIS / NIS*

У референс-моделей (без предсказания) колонка — **NIS\*** (суррогат: шаг оценки между
фиксами). У ядра (`MotionFilterCore`, интерфейс `InnovationAware`) — **настоящий NIS**:
ν = z_x − x⁻, S = P₀₀ + R.

## SC15: почему «ошибка к истине» — НЕ критерий (обязательное пояснение)

На рампе SC15 измерения систематически смещены — истина недостижима ЛЮБОЙ каузальной
моделью (следящий снап честно уезжает вместе с измерениями: базлайн early≈24 м →
late≈86 м, линейный рост — портрет Н-1). Критерий Н-1 для ядра:
**ограниченность абсолютного отклонения** |Γ(x̂) − raw| против D_max (INV-3, независимо
от пер-тиковых дельт) + **детекция** устойчивого расхождения (N_persist → RECOVERING →
ре-привязка ≤ M подтверждений). Ассерт: ни одного тика, где absDev > D_max и событие
дрейфа не активно.
